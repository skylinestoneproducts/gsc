# GSC Daily Report Dashboard

A lightweight static dashboard for Google Search Console daily exports.

## Use
1. Open the deployed `index.html`.
2. Export a CSV from Google Search Console with `Date, Clicks, Impressions, CTR, Position` columns.
3. Import the CSV to see KPI cards, a trend chart, and daily rows.
4. Export CSV to keep a copy.

This version does not connect directly to the Google Search Console API. It uses CSV files selected by the user.
